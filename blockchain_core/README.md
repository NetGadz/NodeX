# NodeX Chain Specification & Roadmap

Этот репозиторий содержит техническую спецификацию и пошаговый план разработки L1-блокчейна NodeX Chain уровня «TON-lite».

## Milestone Roadmap

- [ ] **M0: Скелет workspace, CI, линты, базовые типы**
- [ ] **M1: Криптография и типы**
- [ ] **M2: Хранилище и состояние**
- [ ] **M3: Исполнитель: переводы, комиссии, genesis**
- [ ] **M4: Одиночная нода (devnet)**
- [ ] **M5: P2P и синхронизация**
- [ ] **M6: BFT-консенсус**
- [ ] **M7: Стейкинг, награды, слэшинг**
- [ ] **M8: WASM-VM и газ**
- [ ] **M9: SDK и эталонные контракты**
- [ ] **M10: Кошелёк (CLI + GUI)**
- [ ] **M11: Лёгкий клиент и state sync**
- [ ] **M12: Усиление и тестнет**
