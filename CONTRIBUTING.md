# Contributing

Спасибо, что заинтересовались проектом. Этот проект находится на ранней стадии разработки, поэтому любые идеи, замечания и улучшения особенно ценны.

## Как можно помогать

- улучшать маршрутизацию и поиск по DHT;
- добавлять тесты и сценарии для сетевой логики;
- исправлять баги и edge cases;
- улучшать документацию и примеры запуска;
- предлагать новые протоколы, оптимизации и архитектурные идеи.

## Рекомендуемый процесс

1. Сделайте fork проекта.
2. Создайте ветку для задачи: `feature/...`, `fix/...`, `docs/...`.
3. Внесите изменения и проверьте, что проект собирается и тесты проходят.
4. Откройте pull request с кратким описанием идеи и цели изменения.

## Что важно учитывать

- проект ещё активно развивается, поэтому API и поведение могут меняться;
- лучше сначала обсудить крупные изменения в issues;
- документация и понятные названия важны так же, как и код.

Мы рады любым полезным дополнениям и конструктивным предложениям.
